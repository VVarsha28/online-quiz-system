
# Online Quiz System

A Flask-based online quiz application with:

- User login
- Subject-wise quizzes
- Automatic score calculation
- Dynamic leaderboard
- Rank badges
- MySQL database integration

## Technologies Used

- Python
- Flask
- HTML
- CSS
- MySQL

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Open:

http://127.0.0.1:5000
